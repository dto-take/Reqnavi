# Handoff: 「画面遷移図」（9章 機能要件の下位画面）のUX改善 — 案 7a

## Overview

ReqNavi（案件の要件定義を15章立てで作成・レビューするWebアプリ）の **9. 機能要件 › 画面遷移図** ページの改修デザイン。

**データモデルの前提（重要）**
- 画面遷移図は **「画面（ノード）＋遷移（エッジ）」のシンプルな有向グラフ**
- 業務フロービルダーと異なり、**条件分岐（Yes/No）の構造はない**
- **1つの画面から複数の遷移先が並列に存在しうる**（例：詳細画面→編集画面、詳細画面→削除確認 が同時に成立）
- 各画面ノードは、**9章（機能要件）の画面情報を持つ項目と紐付く場合がある**（画面イメージ機能で表示されるものと同じデータ）

現状（`reference_現状画面遷移図.png`）の問題:
- 図／追加フォーム／削除リストの3か所に情報が分散
- 遷移追加フォームが「遷移元」「遷移先」とも同じ初期値のセレクトで、ラベルもなく意味が読めない。「追加」ボタンが縦に折れている
- 図が小さい固定高・横スクロールで、並列遷移が読み取りにくい
- 9章の画面情報との紐付きが見えない
- **AI一括生成（ノード名＋遷移のみ）しかなく、個別ノードの編集・追加・削除・確定ワークフローがない**
- 削除が素のテキストリンク（遷移は削除不可）

改修方針（採用案 = **7a：キャンバス＋右パネル**）:
1. **キャンバスが主役**。ノードはドラッグで手動配置、必要時に「自動で整列」
2. ノード右端のポート（●）から別ノードへドラッグで**遷移を作成**
3. **右パネルで選択対象を編集**：画面ノード（名前・9章紐付け・遷移先（並列）・遷移元・確定）／遷移（操作名・戻り遷移追加・削除）／未選択時は全体チェック
4. **9章の画面情報をノードに紐付け**て表示。未紐付け・孤立ノードを警告
5. **AI素案は全置換ではなく「差分提案」**：追加すべきノード・遷移を破線で提案し、個別／一括で採用・見送り
6. 章ナビ・配色・タイポ・右パネル構成は **4b／5c／6c と共通**

## Fidelity

**High-fidelity（hifi）**。最終の配色・タイポ・余白・状態遷移を持つ。既存デザインシステムがあればそちらを優先してマップ（緑=primary、琥珀=要確認、破線=AI由来）。

### C. 右パネル（選択対象で3モード）

**C-1. 未選択（全体の確認）**
- 見出し「全体の確認」Shippori Mincho 600/16px
- 「要確認」リスト：各行 枠 `1px solid #ebd7b0` ＋ 左端3px `#d9a341`、画面名＋理由（「9章の画面に未紐付け」「遷移がない（孤立）」を `・` で連結、`#8a5a18`）。クリックでその画面を選択
- 問題がなければ「問題はありません。」`#2f5d45`
- **「9章にあって図にない画面」**リスト：F番号（Mono）＋機能名＋`図に追加`（文字 `#2f5d45`／枠 `#cfd9d2`）。追加するとその9章項目に紐付いたノードが作成され、選択状態になる

**C-2. 画面ノード選択時**
- 画面ID ＋ ステータスピル（確定済／要レビュー／下書き）＋ AI提案ピル（破線）
- 画面名: Shippori Mincho 600/17px、枠 `1px solid #d8d2c4`、クリックで編集
- AI提案ノードの場合: 破線枠カードに「根拠：…」＋`採用`／`見送り`
- **9章の画面情報**
  - 紐付き済: 枠 `#cfd9d2` のカードに F番号（Mono `#2f5d45`）＋機能名、**画面イメージ**（高さ92px、9章の画面イメージ機能と同じデータを表示）、`画面イメージを開く`／`紐付けを外す`
  - 未紐付け: 琥珀カード（地 `#fdf8ee`／枠 `#ebd7b0`）に案内文＋**未使用の9章画面の候補リスト**（クリックで紐付け）
- **遷移先 N**（右に「並列に存在できます」）
  - 各行: `→` ＋ 遷移先画面名（500/12.5px）＋ 操作名（400/11px/`#6f6a5e`）、行クリックでその遷移を選択、`×` で削除（hover で赤系）。AI提案行は破線枠＋`採用`
  - `＋ 遷移先を追加（画面を選ぶ）` → 既に遷移先になっていない画面をチップで表示し、クリックで追加
- **遷移元 N**: `←` ＋ 画面名 ＋ 操作名。0件なら「なし（起点の画面として扱います）」
- アクションバー（sticky bottom）: `この画面を確定`（primary）／確定済表示、右端に `画面を削除`（文字 `#8f3a22`／枠 `#efcbc0`、hover 地 `#fbeae5`）

**C-3. 遷移選択時**
- 「遷移」ピル ＋ AI提案ピル
- 遷移元画面 → ↓ → 遷移先画面（各ボタンでその画面を選択）
- **遷移のきっかけ（操作）**: クリック編集。補足「例：行を選択・保存・キャンセル。条件分岐は持たず、1画面から複数の遷移を並列に定義します。」
- AI提案の場合: 根拠＋`採用`
- `戻りの遷移を追加`（逆向きが無いときのみ）、`遷移を削除`

## Interactions & Behavior

1. **ノード移動**: ドラッグで移動（3px未満の移動はクリック＝選択とみなす）。ステージ内にクランプ。位置は永続化
2. **遷移作成**: ポートからドラッグ→別ノード上で離すと作成（自己ループ・同方向の重複は作らない）。作成後はその遷移を選択し、操作名入力にフォーカス
3. **選択**: ノード／エッジ／ラベルのクリックで選択、背景クリックで解除。選択中の画面に関わる遷移を強調
4. **自動で整列**: 入次数0の画面を起点にBFSで層分けし、層ごとに列（270px間隔）、層内で行（120px間隔）に配置。到達不能ノードは第0層の下へ。**手動配置を上書きするので、実装では実行前に確認 or 元に戻す（Undo）を用意**
5. **画面の追加**: `＋ 画面を追加`（未紐付けの下書きノード）／右パネル「9章にあって図にない画面」から追加（紐付け済で作成）
6. **9章との紐付け**: 1つの9章項目は1ノードにのみ紐付け（候補リストから使用済みは除外）。紐付け解除で未紐付けに戻る
7. **確定ワークフロー**: 画面ノード単位で `下書き → 要レビュー → 確定`。AI提案中のノードは確定不可（先に採用が必要）
8. **AI素案（差分で提案）**: 既存の図・9章の機能要件を入力に、**追加すべきノード／遷移だけ**を返す（既存は変更しない）。各提案に「根拠」1文を必須で付与。提案は破線で表示し、ノード・遷移単位で採用／見送り、またはヘッダーで一括。ノードを見送ると、そのノードに接続するAI遷移も消える。見送った提案は記録して再提案しない
9. **警告の判定**（AI提案を除外して計算）: 9章未紐付け／入出遷移がともに0（孤立）
10. **削除**: 画面削除は接続する遷移も削除（確認ダイアログ推奨）。遷移はパネルの `×` または遷移パネルから
11. **キーボード**: `Delete` で選択対象の削除、`Esc` で選択解除／接続キャンセル、矢印キーで選択ノードを移動（Shift で10px）
12. **ズーム**: 50〜160%。ホイール＋Ctrl/⌘でのズーム、スペース押下ドラッグでのパンも実装推奨
13. **扱わないもの**: 条件分岐（Yes/No）、分岐ノード、遷移の優先順位。並列遷移は同列の関係として扱う

## State Management

サーバ側データ:
- `ScreenNode`: `{ id, projectId, code, name, functionItemId | null, status: 'draft'|'review'|'confirmed', x, y, source: 'human'|'ai', updatedAt, updatedBy }`
- `Transition`: `{ id, projectId, fromNodeId, toNodeId, label, source: 'human'|'ai' }` — `(fromNodeId, toNodeId)` は一意
- `FunctionItem`（9章、既存）: `{ id, code, name, screenImage, ... }`
- `AiSuggestion`: `{ id, kind: 'node'|'transition', payload, why, state: 'open'|'adopted'|'rejected' }`

UI状態: `selection: {type:'node'|'transition', id} | null`、`scale`、`dragging`、`connecting: { fromNodeId, cursor } | null`、`targetPickerOpen`

派生値: 入出次数、警告一覧、「9章にあって図にない画面」（全FunctionItem − 紐付け済）、エッジのパス／ラベル座標、往復ペア判定、サマリ件数

主な操作:
- `moveNode(id, x, y)`（ドラッグ終了時に保存）/ `addNode({name, functionItemId?})` / `renameNode` / `removeNode`（接続遷移も削除）
- `linkFunction(nodeId, functionItemId | null)` / `setStatus(nodeId, status)`
- `addTransition(from, to, label?)` / `updateTransitionLabel` / `removeTransition`
- `autoLayout()` / `generateSuggestions()` / `adopt(id)` / `reject(id)` / `adoptAll()` / `rejectAll()`
