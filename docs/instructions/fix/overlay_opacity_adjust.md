# 指示書：ローディングオーバーレイ背景の透明度を再調整

## 目的

前回`bg-page/40`にした背景を、さらに透明度を上げる（値を下げる）。アイコンのアニメーション自体は変更しない。

## 前提確認

- ローディングオーバーレイの見た目調整（透明度・アニメーション）が完了していること

---

## Step 1: 背景の不透明度を下げる

以下3箇所の`bg-page/40`を`bg-page/15`に変更する。

- `src/app/loading.tsx`
- `src/app/projects/[id]/loading.tsx`
- `src/components/ui/loading-overlay.tsx`

```tsx
className="fixed inset-0 z-[9999] flex items-center justify-center bg-page/15 backdrop-blur-md"
```

**注意**：`backdrop-blur-md`はそのまま維持する（背景がほぼ透けて見える分、ぼかし効果で文字などが乱雑に透けて見えないようにする役割は引き続き必要）。

## Step 2: 動作確認

1. ページ遷移時・ボタン操作時のオーバーレイで、背景がうっすらとした白みを感じさせず、はっきりと透けて見えることを確認する
2. 波紋・パルスのアイコンアニメーションが、透明度を上げた背景の上でも視認性が保たれていることを確認する
3. 文字（「処理中...」等）が背景の内容と重なって読みにくくなっていないか確認する。読みにくい場合は、`bg-page/15`の値を`/20`〜`/25`程度まで戻す、または文字に軽い影（`drop-shadow`等）を付けることを検討する（微調整はお任せする）

## 完了条件

- [ ] 背景の透明度がさらに上がっていることを確認済み
- [ ] 文字・アイコンの視認性に問題が無いことを確認済み
