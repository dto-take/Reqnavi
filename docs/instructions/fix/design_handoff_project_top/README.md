# Handoff: 「案件トップ」画面のUX改善 — 案 9a

## Overview
ReqNavi の案件トップ（`/projects/:id`）の改修。現状（`reference_現状案件トップ.png`）の問題:
- メインの「ステップ」15章一覧が**左サイドバーの章一覧と二重**。しかも状態表現が不一致（ステップ＝チェック有無のみ／サイドバー＝3段階ドット）
- 「資料件数／メンバー／ベースライン未確定」が大きな数字で並ぶが、次の行動に繋がらない
- 「次にやること」が汎用文（「進めましょう」）で、どの章を何件やるのか不明
- ナレッジ（最近確定した項目・資料）が縦に長く、どの章の項目か小さい文字でしか分からない
- Word／PowerPoint出力ボタンがヘッダーカード内で目立つ。「AI素案を一括生成」がサイドバーの小さな文字リンク

改修方針（採用案 **9a**）:
1. **「次にやること」を具体化**して最上部に。1クリックで該当章へ
2. メインの章一覧を**フェーズ別カード（または一覧表）**に置換。**カード／一覧は切替**（選択は永続化）
3. **サイドバーは残す**（章間の移動が速い）。役割は「現在地＋移動」に絞り、メインは「進み具合の確認」
4. ナレッジは右レールに**章名つき**で縮約（最近の動き／最近の資料）
5. Word／PPT出力は「出力 ▾」、「AI素案を一括生成」はヘッダーボタンへ集約

## Interactions & Behavior
1. 表示形式・フェーズの開閉は永続化（ユーザ設定）。章を移動して戻っても保持
2. フィルタは即時反映（章数が少ないためクライアント側）。件数チップはフィルタと独立に全体の件数
3. 章の状態：`確定済`＝全項目確定／`作成中`＝1項目以上確定or入力あり／`未着手`＝入力なし。サイドバー・メイン・章ページで**同一の判定ロジック**を共有すること（現状の不一致の解消）
4. 「出力 ▾」は外側クリック／Esc で閉じる
5. 「AI素案を一括生成」は実行前に確認ダイアログ（既存の確定項目は上書きしない旨を明記）
6. 最近の動き：直近N件（確定・編集）を新しい順に。AIによる変更は破線バッジで区別（他画面と同様）
7. サイドバーは全画面共通コンポーネント。現在地は「案件トップ」または開いている章に移る
8. キーボード：サイドバー／カード／行はすべてフォーカス可能にし、フォーカスリングを表示
