# 提案書：営業管理システム（Salesforce）導入プロジェクト

**顧客名**：株式会社サンライズ商事
**提出日**：2026年7月1日
**提出元**：〇〇システムズ株式会社

## 1. ご検討の背景

株式会社サンライズ商事様（以下、貴社）では、営業活動の管理を各営業担当者が個別のExcelファイルで行っており、以下の課題を抱えている。

- 商談状況が営業担当者個人にしか分からず、上長がリアルタイムに進捗を把握できない
- 見積書の作成が担当者ごとに書式が異なり、承認プロセスも口頭・メールで属人的に行われている
- 顧客情報が部署間で分断され、同じ顧客に対して営業部と既存の基幹システム（会計システム）側の情報が一致しないことがある
- 売上予測が担当者の感覚に依存し、経営層への報告に時間がかかっている

## 2. プロジェクトの目的

Salesforce Sales Cloudを導入し、商談管理・見積管理・承認フローを一元化することで、営業プロセスの可視化と、経営層による迅速な意思決定を可能にする。

## 3. プロジェクトのスコープ

### 対象範囲
- 営業部（東京本社・大阪支社）における商談管理、見積管理、承認フロー
- 既存の基幹システム（会計システム、ベンダー：△△システム社）との顧客情報連携
- 営業担当者・営業マネージャー向けのダッシュボード

### 対象外
- 会計処理そのもの（既存基幹システムを継続利用）
- カスタマーサポート業務（別プロジェクトで検討予定）
- 海外拠点（本プロジェクトでは日本国内拠点のみを対象とする）
