# データ移行要件・運用要件・トレーニング要件

## 1. データ移行要件

現行のExcel台帳「見込み客リスト.xlsx」「受注管理台帳.xlsx」に保存されているデータを、新システムへ移行する必要がある。

- 移行対象：見込み客リスト（約1,200件）、受注管理台帳（過去3年分、約3,500件）
- 移行元：Excelファイル（各拠点の営業担当者PC・共有フォルダに分散）
- 移行先：Salesforce（Lead、Opportunity、Account）
- 移行方法：Salesforceの標準データインポートツールを使用予定。データクレンジング（重複顧客の名寄せ等）が必要になる見込み
- 移行タイミング：本稼働直前の移行リハーサル時、および本稼働時の2回を予定

## 2. システム運用要件

- 本稼働後の障害対応窓口は情報システム部門が担当し、必要に応じてベンダーにエスカレーションする運用とする
- バックアップは日次で自動実行される想定（Salesforce標準機能に依存）
- 利用状況のモニタリングは月次で情報システム部門が実施し、異常な利用（大量データ削除等）が無いか確認する

## 3. トレーニング要件

- 対象：営業担当者約40名、営業マネージャー約8名
- 内容：基本操作（商談登録、見積作成、承認申請）を中心とした研修を本稼働前に実施する
- 実施方法：本社・大阪支社それぞれで対面研修を1回、その後はオンラインでの補足説明会を柔軟に実施する予定
- マニュアル：基本操作マニュアルを別途作成し、社内ポータルに掲載する

## 4. システム定着化支援要件

- 本稼働後3ヶ月間は、情報システム部門と営業企画部門が中心となり、利用状況（ログイン率、商談登録件数）を週次で確認する
- 利用が定着しない拠点・担当者がいた場合、個別にフォローアップを行う
- 四半期ごとに、営業担当者へのアンケートを実施し、改善要望を収集する
