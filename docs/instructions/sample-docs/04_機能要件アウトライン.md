# 機能要件アウトライン（To-Beの業務・機能イメージ）

## 1. To-Be業務フロー概要

Salesforce導入後は、以下の流れに業務を統一する想定である。

1. 見込み客登録：Webサイトの問い合わせフォームと連携し、リード（Lead）情報を自動登録する
2. 初回商談：営業担当者が商談（Opportunity）を作成し、商談内容を記録する
3. 見積作成：Salesforce標準の見積機能で見積書を作成する
4. 見積承認：金額に応じた承認フロー（100万円以上は営業マネージャー承認）をシステム上で実行する
5. 受注登録：受注確定した商談のステータスを更新する（Excel台帳への転記は廃止する）
6. 基幹システムへの反映：受注情報を日次バッチで基幹システムへ連携する（自動承認チェックのステップを新たに設ける想定）

## 2. 必要と考えられる機能（案）

- 顧客管理機能：会社名・部署・担当者・住所等の基本情報を管理する
- 商談管理機能：商談のステータス（提案中・見積提出・受注・失注等）を管理する
- 見積管理機能：見積書の作成・PDF出力を行う
- 承認機能：金額に応じた承認フローを設定する
- ダッシュボード機能：売上・商談件数を集計して可視化する
- 顧客情報連携機能：既存基幹システムとの顧客情報の同期を行う

## 3. 画面イメージ（案）

### 商談一覧画面
- 表示項目：商談名、顧客名、金額、ステータス、担当者
- 操作：検索、新規作成、CSV出力

### 商談詳細画面
- 表示項目：商談名、顧客名、金額、ステータス、活動履歴
- 操作：編集、見積作成、削除

### 見積作成画面（入力フォーム）
- 入力項目：顧客名、商品・サービス名、金額、条件
- 操作：保存、承認申請

### 経営ダッシュボード画面
- 表示指標：今月売上、商談件数、成約率、見込み売上

## 4. 検討中・未確定の事項

- 失注理由の分析機能については、必要に応じて別途検討する
- 名刺管理機能との連携は、今回のスコープに含めるかどうか未確定
- 権限設計（営業担当者が自分の担当顧客のみ見えるようにするか、部署全体で共有するか）は、貴社内で検討中とのことで、方針が固まり次第連携いただく予定
