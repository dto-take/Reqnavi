# KPI設計資料：営業管理システム導入プロジェクト

**顧客名**：株式会社サンライズ商事
**作成日**：2026年8月25日

## 1. KGI（最終ゴール）

本プロジェクトが最終的に達成すべきゴールは以下のとおりである。

**「営業活動のデータドリブン化により、月次の商談成約率を現状の18%から25%へ引き上げる（2027年8月末までに達成）」**

## 2. KGI達成のための目標（KPI階層 上位）

KGI達成のため、以下3つの目標を設定する。

### 目標1：商談プロセスの可視化と標準化
現在、商談の進捗状況が営業担当者個人に閉じており、上長がリアルタイムに把握できていない。この状態を解消し、商談プロセス全体を可視化する。

### 目標2：見積・承認業務のリードタイム短縮
見積書の作成から承認までのプロセスが属人的で、承認までに平均5営業日を要している。これを1営業日程度まで短縮する。

### 目標3：顧客データの一元化と精度向上
顧客情報が営業部と基幹システムに分断されており、情報の不整合が月間平均12件発生している。これをゼロに近づける。

## 3. 目標達成のための戦略・戦術

### 目標1（商談プロセスの可視化）に対応する戦略・戦術

- **戦略：Salesforce商談管理機能への全面移行**
  - 戦術：全営業担当者にSalesforceの商談登録を必須化する運用ルールを策定する
  - 戦術：週次で商談ステータスをダッシュボードで確認する定例会議を新設する

### 目標2（見積・承認リードタイム短縮）に対応する戦略・戦術

- **戦略：承認フローのシステム化**
  - 戦術：金額に応じた承認ルート（100万円以上は営業マネージャー承認）をSalesforce上に設定する
  - 戦術：承認依頼時に自動通知（メール・Slack等）が届く仕組みを導入する

### 目標3（顧客データ一元化）に対応する戦略・戦術

- **戦略：基幹システムとのデータ連携自動化**
  - 戦術：顧客情報を日次バッチで基幹システムと同期する仕組みを構築する
  - 戦術：連携エラー発生時に情報システム部門へ自動アラートを送る

## 4. KPIモニタリングの運用

上記の目標・戦略・戦術は、月次のプロジェクト定例会議で進捗を確認し、必要に応じて内容を見直す。特にKGIに直結する「商談成約率」は、Salesforceのダッシュボード機能で常時モニタリングできる状態を本稼働と同時に整備する。
